О проекте

Учебный сайт-визитка, созданный для отработки навыков Git и GitHub Pages

Что это за проект

Этот сайт — самостоятельная работа по веб-разработке. Его задача — показать умение работать с системой контроля версий Git, создавать семантическую вёрстку, писать адаптивные стили и добавлять интерактивность на чистом JavaScript.

Проект полностью статический: без фреймворков, сборщиков и серверной части. Хостинг осуществляется через GitHub Pages — бесплатно и удобно для учебных целей.

Отдельное внимание уделено доступности: поддержка тёмной темы, анимации с учётом prefers-reduced-motion, семантические теги, alt-тексты и корректная работа с клавиатуры.
