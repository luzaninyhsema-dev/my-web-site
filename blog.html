Разработка 10 октября 2026

Тёмная тема с сохранением в localStorage

Добавили переключатель темы в шапке. Выбор пользователя сохраняется в localStorage и применяется при следующем визите. По умолчанию используется системная тема через media-query.

Типографика: почему Inter

Выбрали шрифт Inter — он отлично читается на любых размерах, поддерживает кириллицу и имеет много начертаний. Подключается одной строкой через Google Fonts.

Первый пуш на GitHub Pages

Настроили репозиторий, добавили README и включили GitHub Pages в настройках. Сайт доступен по адресу luzaninyhsema-dev.github.io/my-web-site/.

Разработка 2 октября 2026

Анимации при скролле

Использовали IntersectionObserver для плавного появления секций. Это нативный API браузера, работает без библиотек и не тормозит страницу.
